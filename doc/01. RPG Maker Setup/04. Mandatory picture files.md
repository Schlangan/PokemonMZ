In order for the plugin to work, some mandatory picture files are required.

## Pokemon team status picture

The plugin will look for a picture named **PokemonMZ_TeamStatus.png** inside the /img/pictures folder. It displays the player/enemy pokeball status list.

## Thrown pokeball picture

For each ball configured (item with effect = ball, see additional file PokemonMZ_Items.json), the plugin will look for a picture named **PokemonMZ_throw_xxxxxx.png**, where xxxxx corresponds to the string id of the ball item. For example *PokemonMZ_throw_pokeBall.png*, or *PokemonMZ_throw_greatBall.png*.
