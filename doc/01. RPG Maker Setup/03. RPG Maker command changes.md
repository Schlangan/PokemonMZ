# Unusable RPG Maker MZ default commands

## Change Gold
Replaced with the plugin commands *Gives Money to Player* and *Takes Money From Player*.

## Change Items
Replace with the plugin commands *Add Item to Storage* (directly set an item inside the player's item PC) and *Add Item to Bag/Lose Item* (add/remove an item to/from the player's bag).

## Change Weapons, Change Armors
Weapons and Armors do not exist with this plugin.

## Change Party Member...
Party members do not exist with this plugin.

## Change HP, MP, TP, State, EXP, Level, Parameter, Skill, Equipment, Class, Profile, Nickname
Actor parameters are not used with this plugin. Only *Change Name...* is operational, and used to change the player's name.

## Player Recover all...
Recovery of the pokemon team is instead done with the pluging command *Heal Party*.

## Game Over
Not used.

## Change Enemy HP, MP, TP, State, Enemy Recover All, Appear, Transform
Enemy parameters are not used with this plugin.

## Show Battle animation, Force Action, Abort Battle
Interpreters do not exist for the Battle Scene, hence those commands are unused.



# New/changed commands

## Message processing
New variables have been added to the message window.
- \PKS : Replaced by the number of Pokemon Seen in the Pokedex.
- \PKO : Replaced by the number of Pokemon Owned in the Pokedex.
- \PK[x] : Replaced by the name of the Pokemon number x.
- \PPK[x] : Replaced by the name of the Pokemon at index x in the party.
- \PPKV[x] : Replaced by the name of the Pokemon in the party at the index stored in variable X. This one is used for example to get the name of the pokemon deposited at day care.
- \DCPK : Replaced by the name of the Pokemon at Day Care.

## Battle processing
Battle processing use troops, which are linked to encounters. You can use them to trigger trainer battles or even wild battles. 

## Player respawn after defeat
The player respawn coordinates are defined with the *Set Player Respawn* plugin command. You must initialize the respawn at the start of your game to not encounter any issues. Then, use the command when the respawn location changes (for example when healing at a Pokemon Center)

## Show Player computer
Used to display the computer of the player, with his items. The Pokemon center PC must have Show Choices options, with one of them using this command.

## Show Pokemon Storage computer
Used to display the storage box system. The Pokemon center PC must have Show Choices options, with one of them using this command.

## Heal Party
Used to completely Heal the team of Pokemons of the player. For now, the storage box is unaffected by this command.

## Give Money to the Player
Gives a specific amount of money to the player.

## Take Fixed Money from the Player
Removes a specific amount of money to the player.

## Take Variable Money from the Player
Removes money to the player, with the value found inside a variable.

## Get Player Money Value
Set the player money value to a chosen variable. Used for checking if the player has enough money, for example.

## Add Item to Storage
Adds an item to the player's computer.

## Add Item to Bag
Adds an item to the player's bag.

## Lose Item
Remove an item from the player's bag.

## Give Badge
Give a badge to the player. Only works with Items specified in the plugin PokemonMZ_Core_Configuration badge parameters.

## Give the Pokedex
Gives a Pokedex to the player, for a specific region ID. The region ID is used in case of multiple pokedexes.

## Add Pokemon Seen To Pokedex
Mark a Pokemon as seen inside the pokedex.

## Can get a Pokemon
Checks if the player can get a pokemon, meaning either their party or current box has room. The return switch becomes ON if the player can get a pokemon. Else it takes the value OFF. An example is only deducting player money when buying a Magikarp if the switch is on. 

## Can get a Pokemon in Party
Checks if the player can get a pokemon in their party, meaning having maximum 5 pokemon with them. The return switch becomes ON if the player can get a pokemon. Else it takes the value OFF. Useful for example with Day Care.

## Give a Pokemon
Adds a Pokemon to the player party. The command is made to select the RPG Maker MZ enemy, which correspond to the Pokemon. The Pokemon will not be given if the party and the current box are full. A switch can be selected in the command, in which case it turns to ON if the pokemon has been given. It is set to OFF if the party+box are full. Messages are automatically displayed to indicate if the pokemon is sent to a box or if the Pokemon couldn't be received, so the event should attempt to give the pokemon, to display those default messages, even if the command Can Get A Pokemon has been used before. 

## Show Current Region Map
Displays the map of the area. The command uses the map info to place the character on the map. See new map mechanics to learn how to configure the map.

## Select Pokemon for Trade
Displays the Pokemon menu for selecting one to trade. This command will check if the selected Pokemon matches the search Pokemon.
- If correct pokemon selected : The chosen variable takes the index of the selected pokemon (0 to 5). This value will be required for the trade command, once implemented
- If wrong pokemon selected : The chosen variable takes the value -1.
- If window canceled : The chosen variable takes the value -2. 

## Play Pokemon Cry
Plays the cry of a pokemon.

## Is Pokemon At Day Care
Returns if a pokemon is currently deposited in the Day Care. Select a switch that will be set ON/OFF according to result.

## Select Pokemon for Day Care
Displays the Pokemon menu for selecting one to place into the Day Care. This command will check if the selected Pokemon doesn't have any HM.
- If Pokemon without HM selected : The chosen variable takes the index of the selected pokemon (0 to 5). This value will be required for the Add Pokemon To Day Care command.
- If Pokemon with HM selected : The chosen variable takes the value -1. Be sure to consider this value, as the pokemon won't be added to day care.
- If window canceled : The chosen variable takes the value -2. 
- If trying to deposit the last non fainted pokemon : The chosen variable takes the value -3. Be sure to consider this value, as the pokemon won't be added to day care.

## Get Day Care Results
Returns the amount of levels gain by the Pokemon at day care, and the price to get back the Pokemon. Select the base cost and the price per level in the formula.

## Play Day Care Pokemon Cry
Plays the cry of the pokemon in the day care. Use it before retrieving the pokemon, or else no cry will play out.

## Retrieve Pokemon From Day Care
Remove the pokemon from day care and add it to the party. The command will not add the pokemon if the party is full. Be sure to check in your event if the party has room, in order to display appropriate messages.


# New map mechanics

A few additional mechanics have been implemented to reproduce some of the behaviour found in Pokemon RBY.

## Event movement limitation

To prevent events from wandering around, place them on a zone with specific region tags. Then, in the note of the event, add the text 
    limitRegion:XXX

Replace XXX with the region tags. Doing so, the event will only move around in tiles with that region.

## Locating the map on the region Map

Region maps data are configured inside the additional Json file PokemonMZ_RegionMaps.json. Each map must be associated with a region id, and the region point of interest. In the note of the maps, add the lines:
    regionId:x
    regionPoi:yy

Replace x with the region Id, and yy by the region point of interest.

## Jumping over ledge

In order to mark ledges, set a region tag to them. Then, in the note of the map, add the line:
    ledgeDownRegion:xx
    ledgeUpRegion:xx
    ledgeLeftRegion:xx
    ledgeRightRegion:xx
    ledgeDownLeftRegion:xx
    ledgeDownRightRegion:xx
    ledgeUpLeftRegion:xx
    ledgeUpRightRegion:xx

Replace xx with the region tag of the ledge. The player will automatically jump when pressing the corresponding direction on the ledge, or during automatic movement from mouse clicking. Be careful to properly add different regions for corners so they can work in both directions of the corner.

## Using escape ropes / dig

In order to make a map available for Escape ropes and the move Dig, add the following line in the note of the map. If the line isn't present, escape ropes or dig won't work on that map.
    escapeRope:true

## Using teleport

In order to make a map available for the use of Teleport, add the following line in the note of the map. If the line isn't present, escape ropes won't work on that map.
    teleport:true

## Wild Pokemon encounters

As all encounters are associated to troops, simply add the encounters in the map properties, and give them a region tag. Be sure to set the region tag to the wild grass, for example. 

## Trainer encounters and aggro range

A new aggro mode has been defined for event triggering. The trainer event will trigger at a given distance, if the player is straight in front. Add the following elements to the event note:
    aggro:xx,page:yy

Replace xx for the number of tiles the trainer sees, and yy by the event page the trigger must be set. Usually, the triggers happens on page 1, and then a self-switch is set after battle. In that case, page 2 with the self-switch condition doesn't trigger with aggro range anymore.
